================================================================================
                        TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: Dashboard shows "Failed to load wallets"
Fix: 
  1. Check backend is running
  2. Verify URL in Settings
  3. Click Test Connection

Issue: Compilation errors
Fix:
  1. Run: pnpm install
  2. Run: pnpm dev
  3. Check node version compatibility

Issue: Mining doesn't start
Fix:
  1. Verify backend supports /mining/start
  2. Check backend logs
  3. Ensure backend is running

Issue: Transactions fail
Fix:
  1. Check wallet has balance
  2. Verify recipient address valid
  3. Check fee is valid
  4. Ensure mining is running
